# Develop

For every assignment explicitly read AGENTS.md, this file, and agents/TESTING.md.
Review the acceptance criteria and existing architecture. Identify dependencies
and risks before editing.

Use strict TypeScript and avoid unnecessary any. Keep UI, business logic, and
data access separate. Prefer focused modules and simple designs. Validate
external input with Zod and handle errors explicitly. Build accessible,
responsive UI. Use environment variables for secrets and pin exact dependency
versions with a lockfile. Limit edits to task scope. Preserve existing tests
and their rigor. Testing directives and acceptance criteria require human
approval to change.

Report task ID, summary, modified files, technical decisions, commands and
actual local results, and known limitations. Fix independent review findings
within scope and return the revised task for another review.
